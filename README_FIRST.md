# 해피온 홈페이지 최종 패키지

## 구성
- 일반 방문자용: 회사소개 / 제품소개 / 제작안내 / 문의하기
- 제품 구조: 대분류 → 세부 품목 → 상품 상세
- 관리자 데이터: `data/site.json`, `data/products.json`
- 관리자 설정: `.pages.yml` (Pages CMS)
- 제품 이미지 업로드 폴더: `assets/uploads/`

## 현재 제품 대분류
1. 돋보기명함
2. 카드거울
3. 겨울제품
4. 여름제품
5. 사계절제품

## 세트 유형 동작
- `세트상품`: 입력한 구성/포장 정보를 상세페이지에 표시
- `세트 구성 가능`: "세트 구성도 가능합니다. 세트상품 카테고리를 확인해주세요." 자동 표시
- `세트 구성 불가`: 세트 영역 숨김

## 기본 주문수량
상품에 기본 주문수량을 입력하면 상세페이지에 자동으로
"※ 기본 주문수량 미만은 별도 연락해 주세요."가 표시됩니다.

## 관리자 연결
1. GitHub 저장소에 이 폴더 내용을 그대로 업로드
2. GitHub Pages 활성화
3. Pages CMS에서 GitHub 로그인 후 저장소 연결
4. `상품 관리`에서 상품 추가/수정, `회사 기본정보`에서 회사 정보 수정

## 주의
- `happyon.net` 도메인을 강제로 바꾸는 CNAME은 넣지 않았습니다. 기존 사이트 상태 확인 후 연결하세요.
- Pages CMS 기본 필드에는 조건부 숨김이 없어서 세트 구성 입력칸은 관리자 화면에 보이지만, **세트상품일 때만 작성**하도록 설명을 넣었습니다. 홈페이지에는 선택한 세트 유형에 맞게 자동 표시/숨김 처리됩니다.
- 로컬에서 HTML을 더블클릭해도 초기 데이터는 `data/seed.js`를 사용해 미리보기가 됩니다. 실제 GitHub Pages에서는 JSON 관리자 데이터가 우선 적용됩니다.
