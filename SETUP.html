SETUP GUIDE

GitHub Pages + 관리자 연결

최초 1회만 설정하면 이후에는 관리자 화면에서 상품과 회사정보를 수정할 수 있습니다.

01

GitHub 저장소 만들기

이 압축파일의 내용을 GitHub 저장소 최상단에 업로드합니다.

02

GitHub Pages 켜기

Repository Settings → Pages에서 배포 브랜치를 설정합니다.

03

Pages CMS 연결

Pages CMS에서 GitHub로 로그인하고 이 저장소 접근을 허용합니다. .pages.yml이 관리자 입력 항목을 정의합니다.

04

상품 관리

상품 관리에서 상품을 추가·수정하고 이미지를 업로드하면 data/products.json이 갱신됩니다.

도메인 happyon.net 연결은 기존 홈페이지 운영 상태를 확인한 뒤 마지막에 진행하는 것을 권장합니다. 이 패키지에는 기존 도메인을 강제로 변경하는 CNAME 파일을 넣지 않았습니다.
